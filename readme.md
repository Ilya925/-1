# CryptoRate — приложение для отслеживания курсов криптовалют

Приложение на Python + Tkinter, которое показывает курсы криптовалют в USD, RUB и EUR, позволяет пересчитать стоимость на нужное количество монет, ведёт историю запросов и поддерживает автообновление.

## Возможности

- **Курсы в нескольких валютах:** USD (от CoinGecko), RUB и EUR (через курс ЦБ РФ).
- **Пересчёт на количество монет:** вводишь число — получаешь итоговую сумму.
- **История запросов:** сохраняется в `history.json`, отображается в отдельном окне таблицей.
- **Автообновление:** можно включить автообновление курса раз в минуту.
- **Устойчивость к сбоям:** обработка ошибок сети, лимитов API, неверного ввода.
- **Логирование:** все ошибки и успешные запросы пишутся в `app.log`.
- **Многопоточность:** сетевые запросы выполняются в фоне — интерфейс не зависает.
